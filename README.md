# 🎋 あみだくじ

くじの数と賞品を先に用意しておき、参加者が**まだ選ばれていないくじを選ぶ**ことで結果が判明する、
本物のあみだくじと同じ手順のローカル Web アプリです。
ブラウザだけで動作し、通信は一切行いません。データは端末内（localStorage）にのみ保存されます。

## 特徴

- **くじを選んで結果が決まる** — 上端のくじは「くじ1／くじ2…」と伏せられた状態で並びます。
  まだ選ばれていないくじをタップすると、そのくじの道すじがたどられ、賞品が判明します。
  最初から名前と結果が紐づいてはいないので、**引く順番や選び方で結果が変わります**。
- **くじの数と賞品を用意（2〜20）** — 「＋／−」でくじの数を決め、賞品名を1つずつ入力します。
- **参加者名は任意** — 登録しておくと「次に引く人」として順に割り当てられ、誰が何を引いたかが結果に残ります。
  登録しなくても、くじ番号のまま引けます。「次に引く人」は好きな人に変更できます。
- **たどるアニメーション** — 選んだくじの道すじを線が下りていきます。引いた人ごとに色が変わります。
- **未確定の賞品は伏せたまま** — まだ誰も到達していない賞品は「？」のまま隠れています。
  最後は「残りのくじをすべて開く」で一気に確認できます。
- **横線の多さを調整** — 「少なめ／ふつう／多め」で、あみだの複雑さを変えられます。
- **賞品の並びをシャッフル** — 賞品の並び順だけを入れ替えます。
- **公平性** — どの縦線どうしも最低1本はつながるように生成するため、まっすぐ下りるだけの列はできません。
  横線は同じ高さで隣り合わないので、道すじは必ず1通りに決まり、賞品はくじと1対1で対応します
  （同じ賞品が2人に当たることはありません）。
- **共有リンク** — 「共有リンクを作成」で、同じあみだくじ（同じ結果）を再現する URL を生成します。サーバー不要です。
- **オフライン動作・自動保存** — 通信不要。引いた結果も含めて自動で端末に保存されます。
- **JSON 書き出し／読み込み** — データのバックアップ・共有ができます。

## 公開URL（GitHub Pages）

このリポジトリを GitHub Pages で公開すると、次の URL でブラウザから直接利用できます。

**https://masaofuruta.github.io/amidakuji/**

### 公開手順（初回のみ）

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を「Deploy from a branch」にします。
3. **Branch** を `main` / `/(root)` に設定して **Save** します。
4. 数十秒〜数分後、上記 URL で公開されます。

> ルート直下の `index.html` がそのまま入口になります。`.nojekyll` を置いているため、Jekyll による変換は行われず、ファイルはそのまま配信されます。

## 使い方

1. 上記の公開URL、または手元の `index.html` をブラウザで開きます（ローカルはダブルクリックでOK。インストール不要）。
2. **① くじの設定** — 「タイトル」を入れ（任意）、「＋／−」で**くじの数**を決め、**賞品名**を1つずつ入力します。
3. **② 参加者（任意）** — 「＋ 名前を追加」で参加者を登録します。くじの数まで登録できます。
4. **③ くじを引く** — 「次に引く人」を確認し（既定では上から順に送られます。変更も可）、
   あみだの上にある**まだ選ばれていない「くじ◯」をタップ**します。
   道すじがたどられ、その人の賞品が判明します。これを人数ぶん繰り返します。
5. 全員ぶん引き終わったら、または途中で残りを確認したくなったら
   「✨ 残りのくじをすべて開く」で残りの対応がまとめて表示されます。
6. 引き直したいときは「結果をリセット（引き直す）」、あみだ自体を作り直すときは「🎲 くじを作り直す」を押します。

> 入力欄を空のままにすると、「賞品1」「参加者1」のように連番で表示されます。
>
> ※ 賞品はあみだの**下端に左から順に**並びます。設定画面の「1番目・2番目…」は下端の並び位置で、
> 上端の「くじ1・くじ2…」とは対応しません。どのくじがどの賞品につながるかは線をたどって決まります。

## 仕組み

- 縦線はくじの数ぶん、横線は `max(8, くじの数 × 2)` 行のあいだにランダムに配置します。
- 同じ行では横線が隣り合わないようにしているため、各行で移動先が一意に決まります。
- 上から出発して横線があれば必ず曲がる、という通常のあみだくじの規則でたどります。
  この操作は置換（順列）になるので、**2人が同じ賞品になることはありません**。
- あみだの形は「くじを作り直す」まで固定です。誰がどの賞品になるかは、
  **どのくじを選んだか**だけで決まります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | 見た目 |
| `app.js` | あみだの生成・道すじの計算・SVG 描画・くじの選択・保存・共有 |
| `.nojekyll` | GitHub Pages で Jekyll 変換を無効化 |

依存ライブラリはありません（バニラ HTML / CSS / JavaScript）。ビルド環境も不要です。

## プライバシー

入力した内容が外部に送信されることはありません。保存先はブラウザの localStorage のみです。
共有リンクは、内容を URL 自体に埋め込む方式（サーバーに保存しない）です。
