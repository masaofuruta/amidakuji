# 🎋 あみだくじ

参加者と結果を入力すると、ランダムなあみだくじを作って結果を決めるローカル Web アプリです。
ブラウザだけで動作し、通信は一切行いません。データは端末内（localStorage）にのみ保存されます。

## 特徴

- **人数可変（2〜20人）** — 参加者名と結果（景品・当番・席番号など）をペアで登録します。
- **たどるアニメーション** — 参加者名をタップすると、その人の道すじを線が下りていきます。
- **1人ずつ／全員まとめて** — 1人ずつ引くことも、「全員の結果を表示」で一気に開くこともできます。
  1人ずつ引くあいだ、まだ誰も到達していない結果は「？」のまま隠れています。
- **横線の多さを調整** — 「少なめ／ふつう／多め」で、あみだの複雑さを変えられます。
- **結果だけシャッフル** — 参加者はそのままに、結果の並びだけを入れ替えます。
- **公平性** — どの縦線どうしも最低1本はつながるように生成するため、まっすぐ下りるだけの列はできません。
  横線は同じ高さで隣り合わないので、道すじは必ず1通りに決まり、結果は参加者と1対1で対応します。
- **共有リンク** — 「共有リンクを作成」で、同じあみだくじ（同じ結果）を再現する URL を生成します。サーバー不要です。
- **オフライン動作・自動保存** — 通信不要。入力は自動で端末に保存されます。
- **JSON 書き出し／読み込み** — データのバックアップ・共有ができます。

## 公開URL（GitHub Pages）

このリポジトリを GitHub Pages で公開すると、次の URL でブラウザから直接利用できます。

**https://masaofuruta.github.io/amidakuji/**

### 公開手順（初回のみ）

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を「Deploy from a branch」にします。
3. **Branch** を `main` / `/(root)` に設定して **Save** します。
4. 数十秒〜数分後、上記 URL で公開されます。

> ルート直下の `index.html` がそのまま入口になります。`.nojekyll` を置いているため、Jekyll による変換は行われず、ファイルはそのまま配信されます。

## 使い方

1. 上記の公開URL、または手元の `index.html` をブラウザで開きます（ローカルはダブルクリックでOK。インストール不要）。
2. 「タイトル」に用途を入力します（任意）。
3. 「＋ 1人ぶん追加」を必要な人数ぶん押し、左に**参加者名**、右に**結果**を入力します。
4. 必要なら「🔀 結果だけシャッフル」「横線の多さ」「🎲 くじを作り直す」であみだを調整します。
5. 参加者名をタップすると道すじがたどられ、下に結果が表示されます。
6. 「✨ 全員の結果を表示」で全員ぶんを一度に開けます。「結果を隠す」で元に戻せます。

> 入力欄を空のままにすると、「参加者1」「結果1」のように連番の名前で表示されます。

## 仕組み

- 縦線は参加者の人数ぶん、横線は `max(8, 人数 × 2)` 行のあいだにランダムに配置します。
- 同じ行では横線が隣り合わないようにしているため、各行で移動先が一意に決まります。
- 上から出発して横線があれば必ず曲がる、という通常のあみだくじの規則でたどります。
  この操作は置換（順列）になるので、**2人が同じ結果になることはありません**。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | 見た目 |
| `app.js` | あみだの生成・道すじの計算・SVG 描画・保存・共有 |
| `.nojekyll` | GitHub Pages で Jekyll 変換を無効化 |

依存ライブラリはありません（バニラ HTML / CSS / JavaScript）。ビルド環境も不要です。

## プライバシー

入力した内容が外部に送信されることはありません。保存先はブラウザの localStorage のみです。
共有リンクは、内容を URL 自体に埋め込む方式（サーバーに保存しない）です。
